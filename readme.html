安装：著名的五分钟安装

  1. 将安装包解压到一个空目录中，然后上传其中的全部文件。
  2. 在浏览器中打开 wp-admin/install.php。安装程序将引导您创建 wp-config.php 文件，并填写数据库连接信息。
    1. 如果上述步骤因某种原因未能完成，请不要担心，部分主机环境可能不支持这一操作。请使用写字板或类似的文本编辑器打开 wp-config-sample.php，并填写数据库连接信息。
    2. 将文件另存为 wp-config.php 并上传。
    3. 在浏览器中打开 wp-admin/install.php。
  3. 配置文件设置完成后，安装程序将为您的站点创建所需的数据表。如果出现错误，请仔细检查 wp-config.php 文件，然后重试。如果仍然失败，请尽可能收集相关信息，并前往 WordPress 支持论坛 寻求帮助。
  4. 如果您没有输入密码，请记下系统为您生成的密码。 如果您没有提供用户名，默认用户名为 admin。
  5. 随后，安装程序会引导您进入 登录页面。请使用安装时设置的用户名和密码登录。如果密码由系统生成，您可以点击「个人资料」进行修改。

更新

使用自动更新功能

  1. 在浏览器中打开 wp-admin/update-core.php 并按照提示操作。
  2. 您可能还在等下一步？已经完成了！

手动更新

  1. 在进行任何更新之前，请确保已备份您可能修改过的所有文件，例如 index.php。
  2. 删除旧的 WordPress 文件，同时保留您修改过的文件。
  3. 上传新文件。
  4. 在浏览器中打开 /wp-admin/upgrade.php。

从其他系统迁移

WordPress 可以 从多种系统导入内容。请先按照上述说明安装 WordPress 并确保其正常运行，然后使用 导入工具。

系统要求

  • PHP 版本 7.4 或更高版本。
  • MySQL 版本 5.5.5 或更高版本。

推荐配置

  • PHP 版本 8.3 或更高版本。
  • MySQL 版本 8.0 或更高版本，或 MariaDB 版本 10.11 或更高版本。
  • 启用 Apache 的 mod_rewrite 模块。
  • HTTPS 支持。
  • 在您的站点上添加指向 wordpress.org 的链接。
